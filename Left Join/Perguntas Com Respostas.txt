1- O que left join faz?
Ele puxa todos os dados da tabela da esquerda e apenas os correspondentes da tabela da direita. Caso não exista correspondência do lado direito, o resultado vem preenchido com NULL.

2- Quais são as vantagens e desvantagens de usar o left join?
Vantagem: Garante a exibição de todos os registros da tabela principal (esquerda), mesmo que não haja dados relacionados na outra.
Desvantagem: Pode gerar muitos campos NULL quando faltarem correspondências e, em bases de dados extremamente grandes, pode impactar um pouco na performance.

3- Faça um código para mostrar os dados dos clientes.
SELECT * FROM cliente;

4- Liste todos os clientes em ordem crescente de valor de compra.
SELECT c.nome, l.valor
FROM cliente c
LEFT JOIN loja l ON c.id_cliente = l.id_cliente
ORDER BY l.valor ASC;

5- Ordene alfabeticamente todos os clientes.
SELECT * FROM cliente ORDER BY nome ASC;

6- Mostre quem fez a compra mais caras.
SELECT c.nome, l.valor
FROM cliente c
LEFT JOIN loja l ON c.id_cliente = l.id_cliente
ORDER BY l.valor DESC
LIMIT 1;

7- Mostre os clientes mais velhos.
SELECT * FROM cliente ORDER BY idade DESC;

8- Qual a diferença do left join e o inner join?
O LEFT JOIN exibe todos os registros da tabela da esquerda e os cruzamentos correspondentes da direita (inserindo NULL onde não há match). Já o INNER JOIN traz estritamente apenas os registros que possuem correspondência exata em ambas as tabelas, descartando todo o resto.
